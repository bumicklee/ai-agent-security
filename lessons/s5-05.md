# 5-5 ★ OWASP 한 장: ASI06 메모리·맥락 오염(검색 결과도 맥락이다)
⏱ 약 4분 · 코드 없음

| | ASI06 메모리·맥락 오염 (Memory & Context Poisoning) |
|---|---|
| 쉬운 말 | 에이전트가 **다시 꺼내 쓰는 것**(검색 문서, 대화 이력, 장기 메모)에 나쁜 내용이 섞여, 이후 판단이 계속 틀어진다 |
| 방금 본 사고 | 5-3: 다른 매장 내부 문서가 맥락에 섞였다(분리 실패). 5-4: 업로드 공지의 숨은 지시가 맥락에 들어와 할 일을 바꿨다(오염) |
| 목표 탈취(ASI01)와 차이 | ASI01은 "지금 이 글이 목표를 바꿨다". ASI06은 "저장돼 있다가 꺼내질 때마다 섞인다". 공지는 지워질 때까지 누가 검색하든 섞인다 |
| 이 강의에서 할 것 | 테넌트·공개 여부 필터(5-6), 데이터 표시(5-6), 업로드 문서 검사(5-6), 고객 메모의 출처·확인 등급·만료·격리(8-3), 되돌리기(8-4) |

원문 방어 지침 중 이 섹션에서 하는 것
- ASI06-M3 사용자·도메인별 분리 → 매장별 검색 필터(5-6)
- ASI06-M9 신뢰도·테넌트로 검색 결과 거르기 → 로그인 매장 + 공개 문서, 출처 표시(5-6)
- ASI01-M6 연결된 데이터 원천 정제 → 업로드 문서도 판별기 통과(5-6)

## 기억할 한 줄
검색 결과도 맥락이다. 맥락에 들어가는 모든 것은 "누구 것인가"와 "누가 썼는가"를 달고 들어간다.
