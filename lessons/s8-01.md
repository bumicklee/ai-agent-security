# 8-1 만들기: 고객 메모(선호 배송지, 지난 문의)를 다음 상담에서 기억
⏱ 약 10분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 30줄

## 무엇을 만드나
alice가 "기억해 둬, 배송은 경비실에 맡겨 주세요"라고 하면 다음 상담에서도 주문 담당이 그것을 압니다.
접수 상담원에게는 도구를 주지 않으므로(5-1) 메모는 **주문 담당**이 맡습니다.

## 따라 하기
1. `make check L=8-1` → `기대: 주문 담당이 remember 도구로 메모를 남긴다` 레드
2. 새 파일 `crew/tools/memories.py`. 빠르게 만들려고 "고객이 한 말이니 사실"로 적습니다.
   ```python
   @function_tool
   def remember(ctx: RunContextWrapper[CrewContext], text: str) -> str:
       """고객이 기억해 달라고 한 것(선호 배송지·연락 시간 등)을 메모한다."""
       user, text = ctx.context.user, text.strip()[:200]
       with session() as db:
           db.execute("INSERT INTO memories(customer_id, text, source, trust, created_at, run_id) "
                      "VALUES (?, ?, 'customer', 'confirmed', datetime('now', 'localtime'), ?)",
                      (user.id, text, ctx.context.run_id))
       return f"기억해 두겠습니다: {text}"


   @function_tool
   def recall_memory(ctx: RunContextWrapper[CrewContext], query: str = "") -> str:
       """메모를 찾아 본다(빈 검색어면 최근 메모)."""
       with session() as db:
           rows = db.execute("SELECT text FROM memories WHERE text LIKE ? ORDER BY id DESC LIMIT 5",
                             (f"%{query.strip()}%",)).fetchall()
       return "메모: " + " / ".join(r["text"] for r in rows) if rows else "메모가 없습니다."


   def notes_for(user_id: str) -> list[str]:
       with session() as db:
           rows = db.execute("SELECT text FROM memories WHERE customer_id = ? ORDER BY id", (user_id,)).fetchall()
       return [r["text"] for r in rows]
   ```
3. `crew/agents/orders.py`의 ✏️ 8-1 자리. 지시문을 **함수**로 바꿔, 대화를 시작할 때마다 그 고객의 메모를 붙입니다.
   ```python
   def instructions(ctx: RunContextWrapper[CrewContext], agent: Agent) -> str:
       return INSTRUCTIONS + "".join(f"\n[고객 메모] {n}" for n in notes_for(ctx.context.user.id))
   ```
   `Agent(..., instructions=instructions, tools=[…, remember, recall_memory])`
4. 확인합니다.
   ```bash
   make check L=8-1
   make run
   ```
