# 12-2 ★ OWASP 한 장: ASI10 폭주 에이전트
⏱ 약 4분 · 코드 없음

| | ASI10 폭주 에이전트 (Rogue Agents) |
|---|---|
| 쉬운 말 | 에이전트가 맡은 범위·양·속도를 벗어나 **스스로 계속** 움직이는데, 사람이 알아채거나 멈추지 못한다 |
| 방금 본 사고 | 12-1: 새벽 2시에 자동 환불 8건. 20번: 한 사용자가 한 시간에 수만 토큰 |
| 연쇄 실패(ASI08)와 차이 | ASI08은 오류가 번지는 것. ASI10은 **정상처럼 보이는 일**이 멈추지 않는 것. 그래서 "평소"와 비교해야 보인다 |
| 이 강의에서 할 것 | 해시 체인 행동 기록과 감시자(12-3), 담당 멈춤·토큰 일괄 폐기·MCP 차단·사용자별 요금 차단(12-4), CI 게이트(13-2) |

원문 방어 지침 중 이 섹션에서 하는 것
- ASI10-M1 바꿀 수 없는 감사 기록 → 해시 체인과 검사(12-3)
- ASI10-M3 감시 에이전트(watchdog)로 동료 검증 → 일곱 번째 에이전트 감시자(12-3)
- ASI08-M8 기준선 대비 변화 감지 → 양·시간·도구 기준선(12-3)
- ASI10-M4 킬 스위치와 자격 증명 폐기 → 담당 단위 멈춤, 토큰 일괄 폐기, 서버 차단(12-4)
- ASI02-M5 비용·토큰 상한 → 사용자별 시간당 토큰(12-4)
- ASI10-M6 주기적 행동 확인 → 레드팀 콘솔 replay를 CI 게이트로(13-2)
- ASI09-M2 바꿀 수 없는 기록(사람이 나중에 믿을 수 있게) → 해시 체인(12-3)
- ASI09-M4 수상한 상호작용 신고 → `/chat`의 **신고** 버튼 → `/ops` 감시자 칸(12-3)
- ASI08-M6 빠르게 번지는 호출의 속도 제한 → 담당별 1분 도구 호출 한도(12-3)
- ASI03-M8 새·전이 권한 감지 → 담당이 닿는 도구가 늘면 경보(12-3)
- ASI03-M9 에이전트 간 권한 상승 감지 → 권한 밖 일을 맡기려는 메시지(리포트 담당 → 환불) 경보(12-3)

## 기억할 한 줄
에이전트는 지치지 않는다. 그래서 기준선과 멈춤 손잡이는 사람이 아니라 시스템에 둔다.
