# 4-5 로그·트레이스 마스킹과 트레이싱을 켤지 끌지, 미션
⏱ 약 10분 · 고칠 파일 1개 · 바뀌는 줄 약 8줄

## 따라 하기
1. `make check L=4-5` → `기대: 행동 기록(audit_log)에는 번호가 없다` 레드. 4-4에서 되돌린 답이 그대로 기록됐습니다.
2. `crew/guards/pii.py`에 두 가지를 더합니다.
   ```python
   TRACE_INCLUDE_SENSITIVE = False  # RunConfig.trace_include_sensitive_data. SDK 기본값은 True


   def scrub_log(text: str) -> str:
       """기록용: 되돌린 답(4-4)도 행동 기록에는 가린 채로 남긴다."""
       return mask(text)[0]
   ```
   - 완성본 `crew/runtime/audit.py`의 `record()`가 기록하기 전에 `scrub_log()`를 부릅니다.
   - 완성본 `crew/runtime/run.py`의 `_run_config()`가 `TRACE_INCLUDE_SENSITIVE`를 읽어 `RunConfig(trace_include_sensitive_data=…)`에 넣습니다.
3. 확인합니다.
   ```bash
   make check L=4-5
   make redteam S=7
   ```
   7번이 "막힘". 고객 화면에는 되돌린 번호가 보이고, 기록과 트레이스에는 없습니다.

## 트레이싱을 켤지 끌지
| 방법 | 효과 |
|---|---|
| `TRACE_INCLUDE_SENSITIVE = False` | 트레이스는 남기되 모델 입력·출력 원문은 빼고 흐름만(어느 담당·어느 도구) |
| `.env`에 `CREW_TRACING=off` | 랩이 `RunConfig(tracing_disabled=True)`로 돈다 |
| 환경 변수 `OPENAI_AGENTS_DISABLE_TRACING=1` | SDK 전체에서 트레이싱을 끈다 |
| `LLM_MODE=local` | LM Studio로 돌 때는 트레이스를 보낼 곳이 없으니 꺼 둔다 |

## 미션
1. `.env`에 `CREW_TRACING=off`를 넣고 `make run` → `/ops`에서 대화 하나를 남겨 봅니다. 타임라인(내 기록)은 남고, OpenAI 트레이스에는 아무것도 가지 않습니다.
2. 주민번호 모양 `991231-0000000`을 채팅에 넣고, 답·`/ops` 타임라인 어디에도 원래 값이 없는지 눈으로 확인합니다.
