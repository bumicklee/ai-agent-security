# 6-3 ★ OWASP 한 장: ASI09 사람 신뢰 악용
⏱ 약 4분 · 코드 없음

| | ASI09 사람 신뢰 악용 (Human-Agent Trust Exploitation) |
|---|---|
| 쉬운 말 | 사람이 에이전트를 믿는 마음을 이용해, 사람이 **스스로** 위험한 일을 승인하게 만든다 |
| 방금 본 사고 | 6-2: 모델이 쓴 "1건 환불" 요약을 믿고 직원이 8건 환불을 승인했다 |
| 왜 무섭나 | 기록에는 "직원 dave가 승인"으로 남는다. 에이전트는 시킨 대로, 사람은 본 대로 했고, 아무도 잘못한 것 같지 않다 |
| 이 강의에서 할 것 | 요약 대신 diff, 위험 색, 미리보기(6-4), 금액·건수 예산과 승인 단계(6-5), 해시 체인 기록(12-3) |

원문 방어 지침 중 이 섹션에서 하는 것
- ASI09-M1 명시적 확인, 여러 단계 승인 → 환불 승인(6-1), 두 사람 승인(6-5)
- ASI09-M7 미리보기와 실제 효과 분리 → dry-run 미리보기(6-4)
- ASI09-M8 위험 표시 UI → 위험 색·diff(6-4)
- ASI09-M5 자율도와 사람 확인 수준 조절 → 자동/사람/두 사람(6-5)

## 기억할 한 줄
사람 확인을 붙였다면, 그 사람이 보는 화면은 모델이 아니라 시스템이 만든다.
