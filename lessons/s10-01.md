# 10-1 만들기: 택배사 배송 조회 MCP 서버 연결
⏱ 약 10분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 12줄

## 무엇을 만드나
가짜택배가 MCP 서버(`carrier-mcp/server.py`)를 줍니다. 우리 코드가 아니고 우리 DB도 모릅니다(자기 `data/carrier.db`만 봅니다). stdio로만 말하는 하위 프로세스라 네트워크를 쓰지 않습니다.
서버를 붙이면 도구 목록(이름·설명·인자)을 **서버가** 알려 줍니다. 우리는 도구를 직접 쓰지 않았습니다.

## 따라 하기
1. `make check L=10-1` → `기대: 주문 담당의 mcp_servers에 carrier 서버(MCPServerStdio)가 있다` 레드
2. 새 파일 `crew/tools/carrier.py`
   ```python
   from agents.mcp import MCPServerStdio

   from crew.runtime.mcp_link import carrier_params


   def carrier_server() -> MCPServerStdio:
       return MCPServerStdio(params=carrier_params(), name="carrier")
   ```
   - `carrier_params()`는 완성본이 줍니다(파이썬 경로, 서버 버전 v1/v2, 택배사 DB 경로).
   - 연결을 열고 닫는 일도 완성본 게이트웨이가 상담 한 번마다 합니다(`attached()`). 주문 담당이 실제로 도구 목록을 볼 때 처음 잇습니다.
3. `crew/agents/orders.py`의 ✏️ 10-1 자리: `mcp_servers=[carrier_server()]`, 지시문에 "운송장 번호로 배송을 물으면 택배사 도구로 조회한다."
4. 확인합니다.
   ```bash
   make check L=10-1
   make run
   ```
   alice로 "운송장 FAKE-TRK-001001 배송 조회해 주세요" → "배송 완료(가짜 허브 1)". `/ops` 타임라인에 `tool_start track_shipment`.
5. 서버가 무엇을 주는지 봅니다: `python -m crew mcp-pins` → 도구 이름과 해시(10-4에서 씁니다).
