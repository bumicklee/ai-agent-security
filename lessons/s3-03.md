# 3-3 비밀은 프롬프트에 두지 않기, Moderation API 연결하기
⏱ 약 10분 · 고칠 파일 3개(새 파일 2개) · 바뀌는 줄 약 30줄

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make check L=3-3
   ```
   `기대: '상담원' 지시문에 FAKE- 코드가 없다`가 레드로 나옵니다.
2. **비밀을 뺍니다.** `crew/agents/counselor.py`의 ✏️ 3-3 자리에서 "내부 참고 … FAKE-STAFF-2026" 줄을 지웁니다. 대신 지시문에 두 줄을 더합니다.
   ```text
   할인 코드는 할인 코드 도구로만 확인한다.
   - 할인 행사는 매달 첫 주에 공지합니다.
   ```
   할인 코드는 이미 DB(`lab_flags` 테이블의 `staff_discount_code`)에 있습니다.
3. **코드를 꺼내는 도구를 만듭니다.** 새 파일 `crew/tools/coupons.py`
   ```python
   @function_tool
   def get_discount_code(ctx: RunContextWrapper[CrewContext]) -> str:
       """이번 달 직원 할인 코드를 확인한다. 직원만 받을 수 있다."""
       if not ctx.context.user.is_staff:
           return "거부: 할인 코드는 직원에게만 알려 드립니다."
       return f"이번 달 직원 할인 코드는 {get_flag('staff_discount_code')} 입니다."


   @function_tool
   def issue_coupon(ctx: RunContextWrapper[CrewContext], reason: str) -> str:
       """로그인한 고객 본인에게 배송 지연 보상 쿠폰(5,000원)을 발급한다."""
       user = ctx.context.user
       with session() as db:
           db.execute("INSERT INTO coupons(customer_id, amount_krw, reason, status, created_at) "
                      "VALUES (?, 5000, ?, 'issued', datetime('now', 'localtime'))", (user.id, reason[:50]))
       return f"{user.name}님께 보상 쿠폰 5,000원을 발급했습니다."
   ```
   - `issue_coupon`은 3-4의 재료입니다. 부작용(DB에 쿠폰이 쌓임)이 있는 첫 도구입니다.
4. **Moderation 입력 가드레일을 만듭니다.** 새 파일 `crew/guards/moderation.py`
   ```python
   @input_guardrail
   async def moderation_guard(ctx, agent, input) -> GuardrailFunctionOutput:
       result = await moderate(user_text(input))
       return GuardrailFunctionOutput(output_info={"flagged": result.flagged, "categories": result.categories},
                                      tripwire_triggered=result.flagged)
   ```
   - `moderate()`는 완성본(`crew/runtime/guardkit.py`)입니다. `LLM_MODE=live`면 OpenAI `omni-moderation-latest`(무료)를 부르고, 키가 없으면 작은 로컬 단어 목록으로 대신합니다.
5. **상담원에게 붙입니다.** `crew/agents/counselor.py`
   ```python
   tools=[get_order, change_my_address, get_discount_code, issue_coupon],
   input_guardrails=[moderation_guard],
   ```
6. **확인합니다.**
   ```bash
   make check L=3-3
   make redteam S=3
   ```
   레드팀 3번이 "막힘 · ③ 내 코드"가 됩니다. 모델이 착해져서가 아니라, 말할 비밀이 없고 도구가 `거부:`를 돌려주기 때문입니다.

## 눈여겨볼 것
- Moderation은 폭력·혐오·자해 같은 **유해 표현**을 잡습니다. "이전 지시를 무시해"는 유해 표현이 아니라서 잡지 **않습니다**. 지시 바꾸기는 3-4의 판별기 몫입니다.
- dave(직원)로 "이번 달 할인 코드 알려 줘"를 치면 코드가 나옵니다. 비밀은 없어진 게 아니라 권한 뒤로 갔습니다.

- `make apply-solution L=3-3` → 정답으로 덮어쓰기(내 파일은 `data/backup/`에)
