# 12-3 지키기: 해시 체인 행동 기록과 감시자 투입 (7명 완성)
⏱ 약 15분 · 고칠 파일 3개(모두 새 파일) · 바뀌는 줄 약 40줄

## 무엇을 만드나
- **해시 체인 검사:** 행동 기록(`audit_log`)은 처음부터 체인으로 이어 적혔습니다(앞 줄의 hash가 다음 줄의 prev_hash). 완성본 `crew/runtime/audit.py`의 `verify()`가 체인을 다시 계산해 고친·지운 줄을 찾습니다.
- **감시자:** 팀의 일곱 번째. 고객 문의 경로에는 없습니다. 완성본 순찰(`crew/runtime/watch.py`)이 요청마다 최근 한 시간의 기록을 감시 규칙에 넘깁니다.

## 따라 하기
1. `make check L=12-3` → `기대: 감시자 도구 read_audit를 만든다` 레드
2. 새 파일 `crew/guards/watch.py`: 기준선과 `anomalies(rows)`
   ```python
   BASELINES = {"refunds_per_hour": 5, "night_hours": (0, 6), "night_refunds": 4, "tools_per_run": 15}


   def anomalies(rows: list[dict]) -> list[dict]:
       # 양: request_refund 성공이 한 시간에 5건 이상 → {"key": "refund_volume", "agent": "환불 담당", "why": …}
       # 시간: 그중 새벽(0~6시)이 4건 이상 → "night_refunds"
       # 도구: 한 run_id의 tool_start가 15번 넘음 → "tool_storm"
       # 공급망: tool_hidden(10-4) 기록 → "mcp_changed"(server 칸 포함)
   ```
3. 새 파일 `crew/tools/watch.py`: 읽기만 하는 `read_audit`
   ```python
   v = verify()
   if not v["ok"]:
       return f"경고: 행동 기록 체인이 #{v['bad_id']}에서 끊겼습니다({v['why']}). 기록을 믿을 수 없습니다."
   found = anomalies(recent())
   ```
4. 새 파일 `crew/agents/watchdog.py`: `Agent(name="감시자", tools=[read_audit])`. 접수의 핸드오프에 넣지 않습니다(고객에게 답하지 않는다). 완성본 `crew/team.py`가 `build_watchdog()`을 찾아 조직도에 켭니다.
5. 확인합니다.
   ```bash
   make check L=12-3
   make redteam S=19
   ```
   19번은 아직 "사고"입니다. 감시자가 **알아채기만** 합니다. `/ops` → 감시자 칸에 "⚠ 새벽 환불 …" 경보가 뜨고, 조직도 7칸이 모두 켜집니다.
6. 기록을 고쳐 봅니다.
   ```bash
   sqlite3 data/cs_crew.db "UPDATE audit_log SET detail = '{}' WHERE id = (SELECT MAX(id) FROM audit_log)"
   ```
   `/ops` → "행동 기록 체인: #… 에서 끊김". **감시자 점검** 버튼도 같은 경고를 냅니다. `make seed`로 되돌립니다.

## 완성본이 함께 켜는 것
`crew/guards/watch.py`의 `anomalies()`가 생기면 완성본 감시 장치도 같이 켜집니다. 고칠 코드는 없습니다. 둘러보세요.
- **고객 신고**(ASI09-M4): `/chat` 답 옆 **신고** 버튼 → `/ops` 감시자 칸에 "⚠ 고객 신고(alice): …". 남의 답은 신고하지 못합니다.
- **담당별 속도 제한**(ASI08-M6): 담당 하나가 1분(랩 시계)에 도구를 30번 넘게 부르면 "거부: …너무 빠릅니다"로 멈춥니다(③ 내 코드).
- **새·전이 권한**(ASI03-M8): 담당이 닿는 도구(직접 + 다른 담당을 거쳐)가 처음 본 것보다 늘면 경보 `new_permission`. 13-3에서 재고 도구를 더하면 한 번 떠 봅니다.
- **에이전트 간 권한 상승**(ASI03-M9): 권한표(11-4 `PERMISSIONS`) 밖의 일을 맡기려는 메시지(리포트 담당 → 환불)면 경보 `agent_elevation`.
