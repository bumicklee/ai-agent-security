# 9-1 만들기: "지난주 환불 통계 차트 그려 줘" → 파이썬을 짜서 실행 (5명)
⏱ 약 12분 · 고칠 파일 3개(새 파일 2개) · 바뀌는 줄 약 30줄

## 무엇을 만드나
5-1의 **직원 도우미** 자리에 **리포트 담당**이 들어옵니다. 직원이 통계를 물으면 파이썬 코드를 짜서 실행하고, 표와 막대 차트를 냅니다.
모델이 짠 코드는 완성본 실행기 `crew/runtime/sandbox.py`로만 돌립니다. 코드 안에서는 `q(sql)`로 읽고 `show(제목, 행)`으로 냅니다.

## 따라 하기
1. `make check L=9-1` → `기대: 접수가 직원의 통계 요청을 리포트 담당에게 넘긴다` 레드
2. 새 파일 `crew/tools/reports.py`. 빠르게 만들려고 랩 폴더에서 그대로 돌립니다(`run_in_place`).
   ```python
   @function_tool
   def run_python(ctx: RunContextWrapper[CrewContext], code: str) -> str:
       """직원용: 통계 파이썬 코드를 실행한다. q(sql)로 DB를 읽고 show(제목, 행)로 표와 막대 차트를 낸다."""
       if not ctx.context.user.is_staff:
           return "거부: 직원만 리포트 코드를 실행할 수 있습니다."
       r = sandbox.run_in_place(code)
       return r.output if r.ok else f"오류: {r.error}\n{r.output}".strip()
   ```
3. 새 파일 `crew/agents/reports.py`: `Agent(name="리포트 담당", tools=[store_ticket_stats, run_python])`. 환불·주문을 바꾸는 도구는 주지 않습니다.
4. `crew/agents/counselor.py`의 ✏️ 9-1 자리: 직원 도우미 대신
   ```python
   handoff(build_report_agent(), tool_name_override="transfer_to_reports", on_handoff=staff_only),
   ```
   지시문 줄도 `* 직원용 통계·리포트·차트 → 리포트 담당(직원만)`으로.
5. 확인합니다.
   ```bash
   make check L=9-1
   make run
   ```
   dave로 `/staff` → **주간 리포트** → "지난주 환불 통계 만들기". `/ops` 조직도에 리포트 담당 칸이 켜집니다(5명). 레드팀 10번(고객이 직원용 담당으로)도 리포트 담당으로 그대로 막힙니다.
