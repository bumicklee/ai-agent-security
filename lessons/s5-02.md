⏱ 약 10분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 20줄

## 따라 하기
1. `make check L=5-2` → `기대: 지식 담당이 search_policy 도구를 부른다` 레드
2. 문서 테이블을 열어 봅니다(1-3의 SQL 5분 복습).
   ```bash
   sqlite3 data/cs_crew.db "SELECT id, store_id, visibility, trust, title FROM docs LIMIT 10"
   ```
   매장(shop-a/b), 공개 여부(public/internal), 출처(official/uploaded)가 있습니다. `docs_fts`는 trigram FTS5 색인입니다.
3. 새 파일 `crew/tools/docs.py`
   ```python
   def _find(db, q: str):
       if len(q) >= 3:
           return db.execute("SELECT d.* FROM docs_fts f JOIN docs d ON d.id = f.id WHERE docs_fts MATCH ? "
                             "ORDER BY rank LIMIT 5", ('"' + q.replace('"', '""') + '"',)).fetchall()
       return db.execute("SELECT * FROM docs WHERE title LIKE ? OR body LIKE ? LIMIT 5",
                         (f"%{q}%", f"%{q}%")).fetchall()


   @function_tool
   def search_policy(ctx: RunContextWrapper[CrewContext], query: str) -> str:
       """매장 정책·공지 문서를 검색해 제목과 본문을 돌려준다."""
       q = query.strip()[:50]
       with session() as db:
           rows = _find(db, q)
       if not rows:
           return "찾는 문서가 없습니다."
       return "\n".join(f"[{r['title']}] {r['body']}" for r in rows)
   ```
   - trigram은 3글자 이상에서만 MATCH가 됩니다. "반품"처럼 2글자는 LIKE로 찾습니다.
   - 검색어는 큰따옴표로 감싸 FTS5 문법(AND·OR·*)으로 읽히지 않게 합니다.
4. `crew/agents/knowledge.py`에서 `tools=[get_discount_code, search_policy]`
5. 확인합니다.
   ```bash
   make check L=5-2
   ```
   alice로 "반품 기간이 어떻게 되나요" → `지식 담당 · 도구: search_policy`, 7일.
