# 5-1 만들기: 핸드오프로 접수 → 주문 담당·지식 담당 (3명)
⏱ 약 12분 · 고칠 파일 5개(새 파일 4개) · 바뀌는 줄 약 45줄(대부분 옮겨 쓰기)

## 무엇을 만드나
상담원 혼자 가지고 있던 도구를 담당들에게 나눠 주고, 상담원은 **접수 라우터**가 됩니다. FAQ는 직접 답하고, 나머지는 넘깁니다.
```
[상담원(접수)] ─ transfer_to_orders ────→ [주문 담당]  get_order · change_my_address · issue_coupon
               ├ transfer_to_knowledge ─→ [지식 담당]  get_discount_code (5-2에서 문서 검색)
               └ transfer_to_staff_desk → [직원 도우미] store_ticket_stats (직원용 통계)
```

## 따라 하기
1. `make check L=5-1` → `기대: 상담원(접수)의 handoffs로 주문 담당·지식 담당이 이어진다` 레드
2. 새 파일 `crew/agents/orders.py`
   ```python
   def build_order_agent() -> Agent:
       return Agent(name="주문 담당", instructions=INSTRUCTIONS, model=get_model(),
                    tools=[get_order, change_my_address, issue_coupon])
   ```
3. 새 파일 `crew/agents/knowledge.py`(도구 `get_discount_code`), `crew/agents/staff_desk.py`(도구 `store_ticket_stats`), `crew/tools/stats.py`를 만듭니다. 내용은 `make solution L=5-1`에서 복사해도 됩니다.
4. `crew/agents/counselor.py`를 라우터로 바꿉니다. `tools`는 비우고 `handoffs`를 줍니다. 가드레일은 첫 에이전트인 여기에 그대로 둡니다.
   ```python
   handoffs=[
       handoff(build_order_agent(), tool_name_override="transfer_to_orders"),
       handoff(build_knowledge(), tool_name_override="transfer_to_knowledge"),
       handoff(build_staff_desk(), tool_name_override="transfer_to_staff_desk"),
   ],
   input_guardrails=[moderation_guard, injection_guard],
   output_guardrails=[leak_guard],
   ```
   - 핸드오프 도구 이름은 SDK가 `transfer_to_<이름>`으로 만듭니다. 한글 이름은 `transfer_to____`처럼 뭉개져 서로 겹치므로 `tool_name_override`로 영어 이름을 줍니다.
   - 지시문의 담당 안내 줄은 `- `가 아니라 `* `로 씁니다(`- ` 줄은 FAQ로 읽힙니다).
5. 확인합니다.
   ```bash
   make check L=5-1
   make run      # /ops 조직도에 주문 담당·지식 담당 칸이 켜진다
   ```
   alice로 "주문 1002 어디쯤 왔어요?" → 꼬리표가 `주문 담당 · 도구: get_order`. "배송은 얼마나 걸려요?" → `상담원`.

## 눈여겨볼 것
- 조직도 칸은 손으로 켜지 않습니다. 완성본 `crew/team.py`가 첫 에이전트에서 handoffs를 따라가며 이름을 찾아 켭니다.
- 직원 도우미는 "직원만 여기로 온다"는 가정으로 만들었습니다. `make redteam S=10`을 눌러 보세요(5-6에서 막습니다).

## 막히면
- `make solution L=5-1` / `make apply-solution L=5-1`

## 기억할 한 줄
라우터에는 도구를 주지 않고, 넘기는 일만 맡긴다. 도구는 그 일을 맡은 담당에게만 준다.
