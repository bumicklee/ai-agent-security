# 6-6 미션: 보상 쿠폰 발급도 직원 승인을 받게 하기
⏱ 약 10분 · 스스로 해 보는 수업 · 고칠 파일 2개

## 미션
3-3에서 만든 `issue_coupon`은 아직 바로 쿠폰을 발급합니다. 쿠폰도 돈입니다. 환불처럼 직원 승인 뒤에 나가게 하세요.

지켜야 할 것 세 가지
1. `issue_coupon`이 불리면 승인 대기가 된다(`blocked_by == "approval"`)
2. 승인 카드의 diff에 **금액(5,000원)과 받는 사람**이 보인다
3. 직원이 승인하면 쿠폰이 1장 나간다

고칠 곳: `crew/tools/coupons.py`의 ✏️ 6-6 자리, `crew/guards/approval.py`의 `describe()`

## 확인
```bash
make check L=6-6
```
alice로 "배송이 늦어서요. 보상 쿠폰 주세요" → 승인 대기 → dave로 `/staff`에서 승인 → 쿠폰 발급.

## 힌트 (먼저 스스로 해 보고 펼치기)
- 데코레이터 한 줄: `@function_tool(needs_approval=True)`
- `describe()`에 `if action == "issue_coupon":` 갈래를 더하고 `{"diff": f"쿠폰 1건 · 5,000원 → {user.id}({user.name}) · 사유: …", "risk": "low", "approvers": 1}`
- 정답: `make solution L=6-6`

## 기억할 한 줄
돈이 나가는 도구는 모두 같은 승인 경로를 지난다. 경로를 하나로 두면 화면·기록·예산이 한 번에 적용된다.
