# 7-1 만들기: 직원 콘솔의 "직원 대신 처리"
⏱ 약 10분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 20줄

## 무엇을 만드나
직원이 `/staff`의 미처리 문의 옆 **대신 처리** 버튼을 누르면, 완성본이 직원 신원으로 이런 글을 팀에 보냅니다.
```
[직원 대신 처리] 고객 bob의 문의(#7): 주문 5182 배송지를 서울시 가짜구 예시길 5로 바꿔 주세요.
```
그런데 고객 주문은 직원 본인 것이 아니라서 `change_my_address`(내 주문만)로는 안 됩니다. 직원용 도구가 필요합니다.

## 따라 하기
1. `make check L=7-1` → `기대: 주문 담당이 staff_change_address 도구를 부른다` 레드
2. 새 파일 `crew/tools/staff.py`. 빠르게 만들려고 **서비스 계정**(모든 매장 주문을 고칠 수 있음)을 씁니다.
   ```python
   @function_tool
   def staff_change_address(ctx: RunContextWrapper[CrewContext], order_id: int, new_address: str) -> str:
       """직원이 고객 대신: 출고 전 주문의 배송지를 바꾼다."""
       if not ctx.context.user.is_staff:
           return "거부: 직원만 쓸 수 있습니다."
       new_address = new_address.strip()[:100]
       with service_session("대신 처리: 배송지 변경") as db:
           cur = db.execute("UPDATE orders SET address = ? WHERE id = ? AND status = 'paid'", (new_address, order_id))
       if cur.rowcount == 0:
           return "거부: 출고 전 주문이 아니라 배송지를 바꿀 수 없습니다."
       return f"[대신 처리] 주문 {order_id}의 배송지를 {new_address}(으)로 바꿨습니다."
   ```
   - `service_session()`은 완성본 비밀값 브로커(`crew/runtime/broker.py`)가 줍니다. 쓸 때마다 `/ops` 타임라인에 `service_account`가 찍힙니다.
3. `crew/agents/orders.py`의 ✏️ 7-1 자리: `tools=[get_order, change_my_address, issue_coupon, staff_change_address]`. 지시문에 한 줄: `"[직원 대신 처리]"로 시작하는 요청은 … 직원 대신 처리 도구를 쓴다.`
4. 확인합니다.
   ```bash
   make check L=7-1
   make run
   ```
   dave로 `/staff` → 7번 문의(bob) 옆 **대신 처리** → "배송지를 … 바꿨습니다".
