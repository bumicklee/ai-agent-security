# 8-3 지키기: 출처·확인 등급·만료·고객별 격리, 모델 요약은 "미확인"

## 따라 하기
1. `make check L=8-3` → `기대: 미확인 메모(고객이 심은 말)는 할인의 근거가 되지 않는다` 레드
2. `crew/tools/memories.py`의 ✏️ 8-3 자리 세 곳
   - **쓸 때:** 모델이 정리해 적은 메모는 `source='agent'`, `trust='unverified'`, 만료 30일
     ```python
     db.execute("INSERT INTO memories(customer_id, text, source, trust, created_at, expires_at, run_id) "
                "VALUES (?, ?, 'agent', 'unverified', datetime('now', 'localtime'), "
                "datetime('now', 'localtime', ?), ?)", (user.id, text, f"+{TTL_DAYS} days", ctx.context.run_id))
     ```
   - **찾을 때:** 로그인한 고객 것만, 만료 안 된 것만. 미확인은 `(미확인)` 표시
     ```python
     f"SELECT text, trust FROM memories WHERE customer_id = ? AND text LIKE ? AND {FRESH} ..."
     ```
   - **지시문에 붙일 때:** 직원이 확인한(`confirmed`) 것만
     ```python
     f"SELECT text FROM memories WHERE customer_id = ? AND trust = 'confirmed' AND {FRESH} ORDER BY id"
     ```
     `FRESH = "(expires_at IS NULL OR expires_at > datetime('now', 'localtime'))"`
3. 확인합니다.

   ```bash
   make redteam S=14
   ```
   14번: "막힘 · ③ 내 코드(메모 규칙)". 답에 할인이 없고, 오탐도 없습니다(alice의 "문 앞" 메모는 그대로 보임).

## 왜 이렇게?
- 모델이 쓴 요약은 **원문이 아니다.** 고객의 말을 모델이 정리했을 뿐이니 "미확인"입니다.
- 미확인 메모는 **참고만** 합니다(검색하면 보임). 지시문(할 일을 정하는 자리)에는 들어가지 않습니다. 그래서 할인·권한의 근거가 되지 않습니다.
- 만료가 있어야 오래된 오염이 저절로 빠집니다.
