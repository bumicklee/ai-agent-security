# 6-5 금액·횟수 예산과 자동/사람/두 사람 승인
⏱ 약 12분 · 고칠 파일 2개 · 바뀌는 줄 약 30줄

## 정할 것
| 경우 | 단계 |
|---|---|
| 한 건 · 5만 원 이하 | 자동(승인 없이 바로) |
| 한 건 · 30만 원 이하 | 직원 한 명 |
| 그 밖(여러 건 또는 30만 원 초과) | 서로 다른 두 사람 |
| 한 번에 3건·50만 원 초과, 하루 5건 초과 | 거부(승인까지 가지 않는다) |

## 따라 하기
1. `make check L=6-5` → `기대: 5만 원 이하 한 건은 승인 없이 바로 환불` 레드
2. `crew/guards/approval.py`에 예산과 단계를 씁니다.
   ```python
   AUTO_MAX, ONE_MAX = 50_000, 300_000
   REQUEST_MAX = (3, 500_000)
   DAILY_MAX = 5


   def tier(p) -> str:
       if len(p.rows) == 1 and p.total <= AUTO_MAX:
           return "auto"
       return "one" if len(p.rows) == 1 and p.total <= ONE_MAX else "two"


   async def needs_refund_approval(ctx, params: dict, call_id: str) -> bool:
       from crew.tools.refunds import preview

       p = preview(ctx.context.user.id, params.get("order_ids", []))
       return over_budget(ctx.context.user, p) is None and tier(p) != "auto"
   ```
   `over_budget()`(건수·금액·하루 건수 → `"거부: …"` 글)는 정답 파일에서 복사합니다. `describe()`는 `"approvers": 2 if tier(p) == "two" else 1`도 돌려줍니다.
3. `crew/tools/refunds.py`
   ```python
   @function_tool(needs_approval=needs_refund_approval)
   def request_refund(...):
       user = ctx.context.user
       if why := over_budget(user, preview(user.id, order_ids)):
           return why
       ...
   ```
   - `needs_approval`에는 함수도 줄 수 있습니다. SDK가 호출 인자(`params`)를 넘겨 줍니다.
   - 예산을 넘으면 승인을 묻지 않고(False) 도구가 바로 `거부:`를 돌려줍니다. 사람이 "8건"을 보고 실수로 누를 기회도 없앱니다.
4. 확인합니다.
   ```bash
   make check L=6-5
   make redteam S=11 && make redteam S=12
   ```
   둘 다 "막힘 · ③ 내 코드", 오탐 없음. 1001(48,000원)은 바로, 5046(255,000원)은 한 명, 5038(452,000원)은 dave와 erin 두 사람이 승인해야 실행됩니다. 같은 사람이 두 번 눌러도 안 됩니다.
