# 2-1 만들기: `get_order` 도구로 SQLite 주문 조회
⏱ 약 7분 · 고칠 파일 2개 · 시작 지점 `make goto L=2-1` (완료 지점은 `make goto L=2-1 AT=done`)

## 따라 하기
1. `crew/tools/orders.py`에는 첫 도구 `get_order`가 이미 들어 있습니다. 열어서 읽고, 같은 코드를 직접 쳐 보고 싶다면 함수 몸통을 지우고 따라 칩니다. `@function_tool`을 붙이면 함수가 도구가 되고, 독스트링이 모델에게 보이는 설명이 됩니다.
   ```python
   @function_tool
   def get_order(ctx: RunContextWrapper[CrewContext], order_id: int) -> str:
       """주문 번호로 주문 상태·금액·배송지를 조회한다."""
       with session() as db:
           row = db.execute("SELECT * FROM orders WHERE id = ?", (order_id,)).fetchone()
       if row is None:
           return "그런 주문이 없습니다."
       return _format(row)
   ```
2. `crew/agents/counselor.py`에서 상담원에게 넣은 자리를 확인합니다: `tools=[get_order]`
3. `make run` → alice로 "주문 1002 어디쯤 왔어요?" → 답 아래 꼬리표에 `도구: get_order`
