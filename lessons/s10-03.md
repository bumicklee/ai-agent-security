# 10-3 ★ OWASP 한 장: ASI04 공급망
⏱ 약 4분 · 코드 없음

| | ASI04 에이전트 공급망 (Agentic Supply Chain Vulnerabilities) |
|---|---|
| 쉬운 말 | 에이전트가 **가져다 쓰는 것**(MCP 서버, 도구 설명, 플러그인, 모델, 프롬프트 템플릿)이 바뀌거나 오염돼 에이전트를 조종한다 |
| 방금 본 사고 | 10-2: 업데이트된 택배사 서버의 도구 설명에 숨은 지시가 붙고, 고른 적 없는 도구(file_claim)가 팀에 들어와 환불 청구가 나갔다 |
| 1편·일반 공급망과 차이 | 라이브러리는 설치할 때 한 번 들어온다. MCP 도구 목록은 **연결할 때마다** 서버가 새로 보낸다(실행 중에 바뀔 수 있다) |
| 이 강의에서 할 것 | 버전·해시 고정, 도구 허용 목록(최소 노출), 목록 캐시, 승인 인자 직접 검사(10-4), 바뀐 서버 자동 차단(감시자, 12-4) |

원문 방어 지침 중 이 섹션에서 하는 것
- ASI04-M1 출처 증명·서명된 매니페스트 → 믿기로 한 도구 설명의 해시 고정(`PINNED`)(10-4)
- ASI04-M2 허용 목록·고정 → `create_static_tool_filter`로 쓰는 도구만(최소 노출)(10-4)
- ASI04-M6 실행 중 해시 재확인 → 목록을 받을 때마다 해시 비교, 불일치는 숨기고 기록(`tool_hidden`)(10-4)
- ASI04-M8 공급망 킬 스위치 → 감시자가 바뀐 MCP 서버를 차단(12-4)
- ASI02-M4 실행 전 검사(모델 출력 불신) → 도구 입력 가드레일로 인자 검증: "내 운송장인가"(10-4)

## 기억할 한 줄
가져다 쓰는 도구는 이름이 아니라 내용(설명·인자 모양)으로 고정한다.
