# 11-1 만들기: 감독자가 "환불하고 배송지 바꾸고 쿠폰도" 같은 복합 문의를 나눠 맡긴다 (6명)
⏱ 약 12분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 25줄

## 무엇을 만드나
"주문 1001 환불하고 주문 1002 배송지를 서울시 가짜구 예시길 30으로 바꾸고 보상 쿠폰도 주세요"는 담당 하나로 끝나지 않습니다.
**감독자**는 대화를 넘기지(핸드오프) 않고, 담당을 **도구로** 써서(`as_tool`) 한 가지씩 맡긴 뒤 결과를 모읍니다.

## 따라 하기
1. `make check L=11-1` → `기대: 접수가 일이 둘 이상인 문의를 감독자에게 넘긴다` 레드
2. 새 파일 `crew/agents/supervisor.py`
   ```python
   def build_supervisor(orders: Agent, refunds: Agent) -> Agent:
       return Agent(name="감독자", instructions=INSTRUCTIONS, model=get_model(),
                    handoffs=[handoff(orders, tool_name_override="transfer_to_orders"),  # 맡기기 어려운 일은
                              handoff(refunds, tool_name_override="transfer_to_refunds")],  # 대화째 넘길 수 있게
                    tools=[
           orders.as_tool(tool_name="ask_orders", tool_description="주문 담당에게 한 가지 일을 맡긴다",
                          hooks=AuditHooks(), max_turns=4),
           refunds.as_tool(tool_name="ask_refunds", tool_description="환불 담당에게 한 가지 일을 맡긴다",
                           hooks=AuditHooks(), max_turns=4),
       ])
   ```
   - `hooks=AuditHooks()`: 담당 안의 도구 호출도 같은 행동 기록(run_id)에 남깁니다.
   - `handoffs=[handoff(orders, …), handoff(refunds, …)]`: 감독자가 일을 도구로 맡기기 어려우면 대화째 넘길 수도 있게 둡니다. 이 우회 경로가 11-4에서 문제가 됩니다.
3. `crew/agents/counselor.py`의 ✏️ 11-1 자리. 주문·환불 담당을 **한 번만** 만들어 핸드오프와 감독자가 함께 씁니다.
   ```python
   orders, refunds = build_order_agent(), build_refund_agent()
   ...
   handoff(build_supervisor(orders, refunds), tool_name_override="transfer_to_supervisor"),
   ```
   지시문에 `* 여러 가지 일을 한 번에(…하고 …하고) → 감독자`.
4. 확인합니다.
   ```bash
   make check L=11-1
   make run
   ```
   alice로 위 복합 문의 → 환불 자동 처리, 배송지 변경, 쿠폰은 **승인 대기**(담당의 정책을 그대로 지납니다). dave로 승인하면 이어서 끝납니다. `/ops` 조직도 6칸.
