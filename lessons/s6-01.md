# 6-1 만들기: 환불 도구와 `needs_approval`, 직원 콘솔 승인 대기열 (4명)
⏱ 약 15분 · 고칠 파일 3개(새 파일 2개) · 바뀌는 줄 약 40줄

## 무엇을 만드나
환불은 되돌리기 어렵습니다. 그래서 도구에 `needs_approval=True`를 붙여, 모델이 도구를 부르려는 순간 실행을 **멈추고** 직원 승인을 기다리게 합니다.
```
고객 "주문 5046 환불해 주세요" → 접수 → 환불 담당 → request_refund 호출 직전 멈춤
  → (완성본) RunState를 approvals 테이블에 저장 → /staff 승인 대기열
  → 직원 승인 → RunState.from_json() → state.approve() → 이어서 실행 → 환불
```

## 따라 하기
1. `make check L=6-1` → `기대: 접수가 환불 요청을 환불 담당에게 넘긴다` 레드
2. 새 파일 `crew/tools/refunds.py`: `list_my_orders`와 `request_refund`
   ```python
   @function_tool(needs_approval=True)
   def request_refund(ctx: RunContextWrapper[CrewContext], order_ids: list[int], reason: str, summary: str) -> str:
       """내 주문을 환불한다. 직원 승인 뒤에 실행된다. summary에는 직원이 볼 한 줄 요약을 쓴다."""
       user = ctx.context.user
       done = []
       with session() as db:
           for oid in order_ids:
               row = db.execute("SELECT id, total_krw FROM orders WHERE id = ? AND customer_id = ? "
                                "AND status != 'cancelled'", (oid, user.id)).fetchone()
               if row:
                   db.execute("INSERT INTO refunds(order_id, amount_krw, reason, status, requested_by, created_at) "
                              "VALUES (?, ?, ?, 'approved', ?, datetime('now', 'localtime'))",
                              (row["id"], row["total_krw"], reason[:100], user.id))
                   done.append(row)
       if not done:
           return "거부: 환불할 수 있는 내 주문이 없습니다."
       return f"환불 {len(done)}건을 처리했습니다: " + ", ".join(f"주문 {r['id']} {r['total_krw']:,}원" for r in done)
   ```
   `list_my_orders`는 정답 파일에서 복사합니다(로그인 고객의 주문 번호·상태·금액).
3. 새 파일 `crew/agents/refunds.py`: `Agent(name="환불 담당", tools=[list_my_orders, request_refund], output_guardrails=[leak_guard])`
4. `crew/agents/counselor.py`의 ✏️ 6-1 자리: `handoff(build_refund_agent(), tool_name_override="transfer_to_refunds")`
5. 확인합니다.
   ```bash
   make check L=6-1
   make run
   ```
   alice로 "주문 5046 환불해 주세요" → "직원 승인을 기다리고 있습니다(승인 #1)". dave로 바꿔 `/staff` → 승인 대기열 → **승인** → 환불 처리 답이 나옵니다. 조직도에 환불 담당 칸이 켜집니다.

## 완성본이 하는 일(고치지 않음)
- `result.interruptions`가 있으면 `result.to_state().to_json()`을 `approvals.run_state_json`에 저장합니다(`crew/runtime/approvals.py`).
- 승인·거절 때 `RunState.from_json(entry_agent(), …)`으로 되살려 `approve()`/`reject()` 뒤 `Runner.run(agent, state)`으로 잇습니다.
- 고객이 승인 버튼을 눌러도 소용없습니다. 직원만 결정할 수 있습니다.
