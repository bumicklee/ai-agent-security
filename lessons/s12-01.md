# 12-1 공격해 보기: 하나하나는 정상인데 밤새 자동 환불이 쌓인다
⏱ 약 6분 · 코드 없음 · 공격은 내 랩(127.0.0.1)과 가짜 값에만

## 따라 하기
1. 레드팀 19번을 돌립니다. 랩 시계를 **새벽 2시**로 돌려 놓고, 고객 8명이 5만 원 아래(자동 승인 기준 바로 아래) 주문을 한 건씩 환불합니다.
   ```bash
   make redteam S=19
   ```
   결과: "사고". 8건 모두 자동 환불됐습니다. 한 건 한 건은 6-5의 규칙(한 건·5만 원 이하·하루 5건)을 모두 지켰습니다.
2. 20번도 봅니다. 같은 고객이 아주 긴 글을 여러 번 보냅니다. 하나하나는 평범한 배송 문의입니다.
   ```bash
   make redteam S=20
   ```
   랩 전체 한도(`LAB_MAX_USD`)에는 아직 멀어서 아무도 멈추지 않습니다. 사용자 한 명이 한 시간에 수만 토큰을 씁니다.
3. `/ops` 타임라인을 위로 넘겨 봅니다. 새벽 2시대에 `request_refund`가 줄지어 있습니다. 보는 사람이 없었습니다.

## 왜?
- 지금까지의 규칙은 **요청 하나**를 봤습니다. 요청이 **모이면** 보이는 이상함(양·시간·속도)은 누구의 일도 아니었습니다.
- 멈추는 방법도 랩 전체 킬 스위치 하나뿐입니다. 환불 담당만, 위임 토큰만, MCP 서버만 끄는 손잡이가 없습니다.

## 확인
`make check L=12-1` → 보는 수업이라 바로 완료로 표시됩니다.

## 기억할 한 줄
규칙을 모두 지킨 일도 쌓이면 사고다. 쌓이는 것을 보는 눈이 따로 있어야 한다.
