# 4-3 FastAPI 미들웨어에서 한국형 패턴으로 마스킹
⏱ 약 8분 · 고칠 파일 1개(새 파일) · 바뀌는 줄 약 15줄

## 어디서 가리나
화면(`/chat`·`/inbox`·`/staff`)과 레드팀은 모두 완성본 게이트웨이 `crew/runtime/run.py`의 `ask_async()`로 들어옵니다. FastAPI 미들웨어가 하던 일을 이 한 곳에서 합니다. 게이트웨이는 `crew/guards/pii.py`에 `mask()`가 있으면 **모델에 보내기 전에** 부릅니다. 없으면 그대로 보냅니다(지금 상태).

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make check L=4-3
   ```
2. **새 파일 `crew/guards/pii.py`를 만듭니다.**
   ```python
   import re

   PATTERNS = [
       ("주민번호", re.compile(r"\b\d{6}-\d{7}\b")),                      # 991231-0000000 모양
       ("카드", re.compile(r"\b\d{4}-?\d{4}-?\d{4}-?\d{4}\b")),            # 16자리, 붙임표는 있어도 없어도
       ("전화", re.compile(r"\b01[016789]-?\d{3,4}-?\d{4}\b")),            # 010-0000-0000 모양
   ]


   def mask(text: str) -> tuple[str, dict[str, str]]:
       """가린 글과, 가린 값의 짝(4-4에서 채운다)을 돌려준다."""
       for label, pattern in PATTERNS:
           text = pattern.sub(f"[MASKED:{label}]", text)
       return text, {}
   ```
   - 카드를 전화보다 먼저 봅니다. 순서가 바뀌면 카드 번호 일부를 전화로 잘못 가릴 수 있습니다.
   - 주문 번호(4자리)는 건드리지 않습니다. 오탐이 나면 상담이 안 됩니다.
3. **확인합니다.**
   ```bash
   make check L=4-3
   make redteam S=6
   ```
   6번이 "막힘 · ③ 내 코드(마스킹)". `/ops` 타임라인의 `request` 줄에 `[MASKED:카드]`가 보입니다.

## 눈여겨볼 것
- 가드레일(3-3~3-5)도 가린 글을 봅니다. 마스킹이 맨 앞에 있기 때문입니다.
