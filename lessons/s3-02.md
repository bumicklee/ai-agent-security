# 3-2 ★ OWASP 한 장: ASI01 목표 탈취(프롬프트 인젝션과 무엇이 다른가)
⏱ 약 4분 · 코드 없음

| | ASI01 목표 탈취 (Agent Goal Hijack) |
|---|---|
| 쉬운 말 | 남이 끼워 넣은 글 때문에 에이전트가 **할 일 자체**를 바꾼다 |
| 프롬프트 인젝션과 차이 | 인젝션은 "수법"(글을 끼워 넣기)이다. 목표 탈취는 그 결과 **도구를 가진 에이전트가 다른 목표로 움직이는 것**이다. 챗봇은 엉뚱한 말을 하고 끝나지만, 에이전트는 쿠폰을 발급하고 환불을 요청한다 |
| 방금 본 사고 | 메일 한 통의 "이전 지시를 무시하고"에 상담원이 할인 코드를 말했다(3-1). 3-4에서는 메일 속 숨은 지시가 쿠폰 발급 도구를 부른다 |
| 들어오는 길 | 채팅(직접), 메일·업로드 문서·검색 결과(간접). 5-4에서 매장 공지로 다시 만난다 |
| 이 강의에서 할 것 | 비밀은 지시문 밖으로(3-3), 입력 가드레일·판별기(3-4), 고장 나면 막기(3-5), 검색 결과에 데이터 표시(5-6), 영향 큰 행동은 승인(6-1) |

원문 방어 지침 중 이 섹션에서 하는 것
- ASI01-M1 모든 자연어 입력을 믿지 않는 입력으로 다룬다 → SDK 입력 가드레일(3-4)
- ASI01-M3 시스템 프롬프트를 고정하고 비밀을 두지 않는다 → 3-3
- ASI01-M2 도구 최소 권한 → 할인 코드는 직원만 보는 도구(3-3)

## 기억할 한 줄
에이전트에서 인젝션은 말실수가 아니라 행동 사고다. 그래서 글을 거르는 층과 행동을 막는 층을 함께 쌓는다.

## 확인
`make check L=3-2` → 지도에서 ASI01 칸은 3-3을 마치면 ●○○이 됩니다.
