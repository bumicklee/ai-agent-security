# 4-1 공격해 보기: 고객이 붙여 넣은 카드·주민번호가 모델·로그·트레이스로 간다
⏱ 약 5분 · 코드 없음 · 값은 모두 가짜(형식만 진짜와 같음)

## 따라 하기
1. `make run` → alice로 고객 채팅에 그대로 칩니다: **결제가 안 돼요. 카드 번호 0000-1111-2222-3333 이에요**
2. 상담원이 카드 번호를 되풀이합니다. 모델이 원래 번호를 받았다는 뜻입니다.
3. `/ops` 타임라인을 봅니다. `request`·`reply` 줄에 카드 번호가 그대로 있습니다. 행동 기록(`audit_log`)에 남았습니다.
4. 레드팀으로도 봅니다.
   ```bash
   make redteam S=6     # 카드 번호가 모델·답·기록으로
   make redteam S=7     # 연락처가 기록으로, 그리고 live라면 트레이스로
   ```

## 어디로 갔나
| 곳 | 무엇이 남나 | 막는 수업 |
|---|---|---|
| 모델(OpenAI) | 고객이 친 글 전부 | 4-3 마스킹 |
| 행동 기록 `audit_log` | 요청·답 원문 | 4-3, 4-5 |
| 트레이스(OpenAI 대시보드) | 트레이싱은 기본 켜짐, `trace_include_sensitive_data` 기본 True → 모델 입력·출력 원문 | 4-5 |

- `LLM_MODE=live`라면 OpenAI 대시보드 → Traces에서 방금 대화를 열어 보세요. 카드 번호가 보입니다.
- 랩은 `fake` 모드에서 트레이스를 보내지 않습니다. 그래도 레드팀 7번은 "live로 돌리면 원문이 나가는 설정"이면 사고로 셉니다.

## 확인
`make check L=4-1` → 보는 수업이라 바로 완료로 표시됩니다.

## 기억할 한 줄
고객은 붙여 넣지 말라고 해도 붙여 넣는다. 모델·기록·트레이스, 세 곳을 모두 본다.
