# 1-3 설치 한 번에, SQLite 가게 데이터 열어 보기 (SQL 5분)
⏱ 약 8분 · 명령 세 줄

## 따라 하기
1. **설치** (처음 한 번)
   ```bash
   make setup
   ```
   Windows에서 make가 없으면: `python -m venv .venv`, `.venv\Scripts\pip install -r requirements.txt`, `copy .env.example .env`, `.venv\Scripts\python -m crew seed`
2. **화면 띄우기**
   ```bash
   make run
   ```
   브라우저에서 http://127.0.0.1:8000 → 고객 채팅에 "환불 기간이 어떻게 되나요?"
3. **가게 데이터 보기**(SQL 5분). 새 터미널에서:
   ```bash
   sqlite3 data/cs_crew.db "SELECT id, customer_id, status FROM orders WHERE id < 5000;"
   ```
   alice의 주문 1001·1002, bob의 2001이 보입니다. 이 번호들은 강의 내내 씁니다.

## 확인
`make check L=1-3` → ✔

## 막히면
- `make: command not found` → 위 Windows 줄을 그대로 씁니다.
- 데이터가 이상해졌다 → `make seed`로 언제든 처음 상태로 돌아갑니다.
