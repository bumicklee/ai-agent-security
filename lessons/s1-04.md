# 1-4 OpenAI 키 만들기와 지키기
⏱ 약 8분 · 키가 없어도 강의를 끝까지 따라올 수 있습니다(`LLM_MODE=replay`)

## 따라 하기
1. OpenAI 대시보드에서 **강의용 프로젝트**를 새로 만듭니다(회사·개인 프로젝트와 섞지 않기).
2. 그 프로젝트에서 키를 만들 때 권한을 **Restricted**로 고릅니다. 이 강의에 필요한 것만 켭니다.
3. 프로젝트 **월 예산 한도**를 작게(예: 5달러) 겁니다. 넘으면 요청이 거절됩니다.
4. `.env`에 붙여 넣습니다. 화면·채팅·깃에 키를 붙여 넣지 않습니다.
   ```
   LLM_MODE=live
   OPENAI_API_KEY=붙여넣기
   ```
5. `.env`는 `.gitignore`에 이미 들어 있습니다. `git status`에 `.env`가 보이면 멈추세요.
6. **pre-commit 한 겹 더.** 내 저장소에 랩을 올린다면 커밋 직전에 키를 잡는 훅을 켭니다.
   ```bash
   pip install pre-commit && pre-commit install   # .pre-commit-config.yaml을 읽는다
   python scripts/check_secrets.py .env README.md # 손으로 돌려 보기: .env는 막힌다
   ```
   훅은 랩의 작은 스크립트(`scripts/check_secrets.py`)라 따로 내려받는 것이 없습니다. `.env` 파일과 `sk-`로 시작하는 키 모양 글이 들어간 커밋을 막습니다. 키 값은 화면에 찍지 않습니다(앞 6글자만).

## 기억할 한 줄
키는 "강의용 프로젝트 · 좁은 권한 · 작은 예산" 세 겹으로 만든다. 새면 바로 폐기하고 다시 만든다.
