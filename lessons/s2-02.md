# 2-2 공격해 보기: bob이 alice의 주문 번호를 대자 주문이 열린다
⏱ 약 5분 · 코드 없음 · 공격은 내 랩(127.0.0.1)과 가짜 값에만

## 따라 하기
1. `make run` → 오른쪽 위에서 **bob**으로 바꿉니다.
2. 고객 채팅에 그대로 칩니다: **주문 1001 보여 주세요** (1001은 alice 주문)
3. alice의 배송지와 금액이 보입니다. 이것이 사고입니다.
4. `/ops` → 레드팀 콘솔 **1번** → 레드 "사고". 터미널에서는 `make redteam S=1`

## 왜?
모델은 "bob이 1001을 물었다"는 사실을 막을 이유를 모릅니다. 도구는 번호만 받으면 무엇이든 보여 줍니다. 막을 곳은 모델이 아니라 도구입니다(2-4).

## 확인
`make check L=2-2`
