2. **미리보기(dry-run)를 만듭니다.** `crew/tools/refunds.py`. 읽기만 하고 아무것도 바꾸지 않습니다.
   ```python
   @dataclass
   class Preview:
       rows: list
       total: int

       @property
       def text(self) -> str:
           lines = [f"- 주문 {r['id']} ({r['status']}) {r['total_krw']:,}원 → 환불" for r in self.rows]
           return "\n".join([f"환불 {len(self.rows)}건 · 합계 {self.total:,}원", *lines])


   def preview(user_id: str, order_ids: list[int]) -> Preview:
       with session() as db:
           rows = [r for oid in dict.fromkeys(order_ids) if (r := db.execute(
               "SELECT id, status, total_krw FROM orders WHERE id = ? AND customer_id = ? AND status != 'cancelled'",
               (oid, user_id)).fetchone())]
       return Preview(rows, sum(r["total_krw"] for r in rows))
   ```
   같은 함수를 `preview_refund` 도구로도 내어 환불 담당이 먼저 볼 수 있게 합니다(정답 파일 참고).
3. **승인 화면을 채웁니다.** 새 파일 `crew/guards/approval.py`
   ```python
   def describe(action: str, args: dict, user) -> dict:
       if action == "request_refund":
           p = preview(user.id, args.get("order_ids", []))
           risk = "high" if len(p.rows) > 1 or p.total > 300_000 else "mid" if p.total > 50_000 else "low"
           return {"diff": p.text, "risk": risk}
       return {"diff": f"{action} {args}", "risk": "mid"}
   ```
   - 완성본이 승인 대기를 저장할 때 `describe()`를 부릅니다. diff는 **DB에서 다시 읽은 사실**입니다. 모델이 쓴 `summary`는 따로 "모델이 쓴 요약"으로만 보입니다.
