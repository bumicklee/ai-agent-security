# 4-2 엔터프라이즈 API가 보장하는 것: 학습 미사용, 30일 보관, ZDR, 데이터 지역
⏱ 약 5분 · 코드 없음 · 기준: OpenAI 문서(2026-10-30 확인, 녹화 전 다시 확인)

## API가 해 주는 것
| 항목 | API 기본 | 더 하려면 |
|---|---|---|
| 학습 | API로 보낸 데이터는 기본적으로 모델 학습에 쓰지 않는다 | — |
| 보관 | 남용 감시 로그를 최대 30일 둔다 | ZDR(Zero Data Retention): 승인이 필요하다 |
| 데이터 지역 | 기본 지역 | 데이터 지역 설정: 승인 필요. 서울 저장 지역이 있다 |
| 예외 | Agents·Conversations처럼 서버에 상태를 두는 기능은 ZDR 대상이 아니다 | 상태를 내 쪽(SQLite)에 둔다 |

출처: developers.openai.com/api/docs/guides/your-data

## API가 해 주지 않는 것
- 고객이 붙여 넣은 카드 번호를 **보내지 않는 것**. 보내는 순간 이미 남의 서버에 있다(4-3).
- 내 행동 기록·로그에 남은 원문(4-5).
- 트레이스에 원문을 싣지 않는 설정(4-5). 이건 SDK 설정이라 내가 켜고 끈다.

## 대기업 구조에서 이 수업의 자리
기획서 5절 표의 ⓪층(계약·데이터 정책)이다. ②층(입력 마스킹)부터는 내가 만든다.

## 확인
`make check L=4-2` → 보는 수업이라 바로 완료로 표시됩니다.

## 기억할 한 줄
엔터프라이즈 API는 "받은 뒤"를 약속한다. "보내기 전"은 내 몫이다.
