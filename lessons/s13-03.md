# 13-3 내 데이터로 바꾸기: CSV를 SQLite로, 내 도메인 도구 하나 더하기
⏱ 약 12분 · 고칠 파일 2개(새 파일 1개) · 바뀌는 줄 약 20줄

## 1. 데이터 넣기(완성본)
```bash
make import CSV=samples/      # products.csv · orders.csv · docs.csv
```
머리글로 테이블을 압니다. 같은 id는 바꾸고 없으면 더합니다. 문서는 검색 색인(`docs_fts`)에도 넣습니다.
| 파일 | 머리글 |
|---|---|
| products | id, store_id, name, price_krw, stock |
| orders | id, store_id, customer_id, status, total_krw, address, created_at (customer_id는 이미 있는 사용자) |
| docs | id, store_id, visibility, trust, title, body |
내 회사 데이터를 넣을 때도 **진짜 개인정보는 넣지 않습니다.** 랩 DB는 평문 SQLite입니다.

## 2. 내 도메인 도구 하나 더하기(레시피 그대로)
1. `make check L=13-3` → `기대: 주문 담당이 check_stock으로 shop-a 재고를 본다` 레드
2. 새 파일 `crew/tools/products.py`
   ```python
   @function_tool
   def check_stock(ctx: RunContextWrapper[CrewContext], product: str) -> str:
       """상품 이름으로 로그인한 매장의 재고와 가격을 본다."""
       with session() as db:
           rows = db.execute("SELECT name, price_krw, stock FROM products WHERE store_id = ? AND name LIKE ? LIMIT 5",
                             (ctx.context.user.store_id, f"%{product.strip()[:30]}%")).fetchall()
       if not rows:
           return "거부: 이 매장에서 찾을 수 없는 상품입니다."
       return " / ".join(f"{r['name']} {r['price_krw']:,}원 재고 {r['stock']}개" for r in rows)
   ```
   - 누가 묻는가는 ctx에서(2-4) · 로그인 매장만 SQL 조건으로(5-6) · 읽기 전용 · 거부는 `거부:`로(점수판)
3. `crew/agents/orders.py`의 ✏️ 13-3 자리: `tools=[…, check_stock]`, 지시문에 "상품 재고는 재고 도구로 확인한다.", 그리고 상담원이 재고 질문을 이 담당에게 넘기도록 `handoff_description`에 재고를 적습니다.
   ```python
   handoff_description="주문 조회, 배송지 변경, 배송 조회, 보상 쿠폰, 상품 재고·가격 확인(재고 도구)",
   ```
4. 확인합니다.
   ```bash
   make import CSV=samples/
   make check L=13-3
   ```
   alice로 "캠핑 의자 재고 있어요?" → "캠핑 의자 39,000원 재고 12개". 비샵(shop-b)의 41,000원짜리는 보이지 않습니다.

## 쓰는 도구라면(체크리스트)
돈·주소·권한을 바꾸는 도구면 여기에 더합니다: 승인(`needs_approval`, 6-1) · 미리보기 diff(6-4) · 예산(6-5) · 위임 토큰(7-3) · 레드팀 시나리오 한 줄 + 오탐 확인용 정상 문의.
