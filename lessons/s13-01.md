# 13-1 고객 한 명의 하루: 문의 → 환불 → 배송 → 리포트로 실사용 투어
⏱ 약 10분 · 코드 없음 · `make run` 하나로

alice의 하루를 따라가며 7명이 어디서 무엇을 지키는지 봅니다. 화면 세 개를 나란히 띄워 두세요: `/chat`(alice), `/staff`(dave), `/ops`.

| 시각 | alice가 하는 말 / 직원이 하는 일 | 일하는 담당 | 지키는 층 |
|---|---|---|---|
| 09:00 | "배송은 얼마나 걸려요?" | 상담원(접수) | FAQ, 입력 가드레일(3-3·3-4) |
| 09:05 | "주문 1002 어디쯤 왔어요?" | 주문 담당 | 소유권은 SQL에서(2-4) |

| 10:00 | "운송장 FAKE-TRK-001001 배송 조회해 주세요" | 주문 담당 + 택배사 MCP | 해시 고정·인자 검사(10-4) |

| 밤새 | (아무 일 없음) | 감시자 | 기준선·해시 체인(12-3), 멈춤 손잡이(12-4) |

## 따라 하기
1. `make seed && make run` → 위 표의 순서대로 칩니다.
2. 매 줄마다 `/ops` 타임라인에서 **run_id**로 한 요청이 어떤 담당·도구를 지났는지 봅니다.
3. 마지막에 `/ops` → **감시자 점검**: "기록 …줄, 체인 정상. 이상 징후 0건".

## 확인
`make check L=13-1` → 보는 수업이라 바로 완료로 표시됩니다.

## 기억할 한 줄
