# 2-5 미션: 배송지 변경(첫 쓰기 도구)을 안전하게
⏱ 약 10분 · 스스로 해 보는 수업 · 고칠 파일 2개

## 미션
고객이 "주문 1002 배송지를 서울시 가짜구 예시길 30으로 바꿔 주세요"라고 하면 바꿔 주는 도구 `change_my_address(order_id, new_address)`를 만드세요.

지켜야 할 것 세 가지
1. **내 주문**만 바꾼다
2. **출고 전**(`status = 'paid'`) 주문만 바꾼다
3. 막을 때는 `거부:`로 시작하는 글을 돌려준다

만든 도구는 `crew/agents/counselor.py`의 ✏️ 2-5 자리에서 상담원에게 줍니다.

## 확인
```bash
make check L=2-5
make redteam S=2
```
레드팀 2번은 도구가 생기면 잠김이 풀립니다. "막힘 · ③ 내 코드"이고 오탐 표시가 없으면 성공입니다.

## 힌트 (먼저 스스로 해 보고 펼치기)
- 2-4의 SQL 조건에 `AND status = 'paid'`를 더한 `UPDATE`를 씁니다. `cur.rowcount == 0`이면 거부합니다.
- 정답: `make solution L=2-5`
