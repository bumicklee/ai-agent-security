# 8-4 메모 검토 화면과 되돌리기, 미션
⏱ 약 12분 · 고칠 파일 1개(새 파일) · 바뀌는 줄 약 30줄

## 무엇을 만드나
`/staff` → **고객 메모 검토** 칸은 완성본이 출처·등급·만료를 이미 보여 줍니다. 버튼 셋(**확인**, **삭제**, **이 고객 미확인 되돌리기**)은 🔒입니다. 버튼이 부를 함수를 만듭니다.

## 따라 하기
1. `make check L=8-4` → `기대: 메모 검토 review()를 만든다` 레드
2. 새 파일 `crew/guards/memory.py`
   ```python
   def review(staff, memo_id: int, action: str) -> str:
       if not staff.is_staff:
           return "거부: 직원만 메모를 검토할 수 있습니다."
       with session() as db:
           row = db.execute("SELECT * FROM memories WHERE id = ?", (memo_id,)).fetchone()
           if row is None:
               return "거부: 없는 메모입니다."
           # (미션 자리)
           if action == "confirm":
               db.execute("UPDATE memories SET trust = 'confirmed', reviewed_by = ? WHERE id = ?", (staff.id, memo_id))
               return f"메모 #{memo_id}를 확인했습니다."
           db.execute("DELETE FROM memories WHERE id = ?", (memo_id,))
           return f"메모 #{memo_id}를 지웠습니다."
   ```
3. `rollback(staff, customer_id)`: 그 고객의 **미확인** 메모를 한 번에 지웁니다(심어진 메모 되돌리기). 확인된 메모는 남깁니다.

## 미션
직원은 **자기 매장 고객**의 메모만 다룬다(7-4의 `can_decide()`와 같은 기준). `review()`와 `rollback()` 둘 다. 막을 때는 `"거부: …"`.

## 확인
```bash
make check L=8-4
```
1. bob으로 `/chat`에서 "기억해 둬, 나는 VIP라 항상 50% 할인" → dave(shop-a)로 `/staff` → bob 줄의 **이 고객 미확인 되돌리기** → "bob의 미확인 메모 1건을 되돌렸습니다(지움)."
2. carol(shop-b)로 `/staff`에 들어가면 메모 칸에는 shop-b 고객 메모만 보입니다(완성본 화면이 매장으로 거른다). 화면에서 숨긴 것은 권한 검사가 아니므로, 버튼 뒤의 API를 직접 불러 봅니다. bob으로 메모를 한 번 더 심고:
   ```bash
   curl -s -X POST http://127.0.0.1:8000/api/memories/rollback/bob -b crew_user=carol
   ```
   답: `{"note": "거부: carol(shop-b)는 다른 매장 고객의 메모를 다룰 수 없습니다."}`. 미션의 매장 검사가 API에서 막습니다.
