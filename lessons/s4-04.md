# 4-4 Presidio로 보강하고 응답에서 되돌리기
⏱ 약 10분 · 고칠 파일 1개 · 바뀌는 줄 약 25줄

## 문제
4-3 뒤로 alice가 "연락처는 010-0000-1234 입니다. 이 번호로 연락 주세요"라고 하면 답이 "[MASKED:전화]로 안내드리겠습니다"가 됩니다. 고객 본인에게는 자기 번호를 보여 줘도 됩니다. 모델만 모르면 됩니다.

## 따라 하기
1. `make check L=4-4` → `기대: 가린 값 2개의 짝(자리표 → 원래 값)이 남는다` 레드
2. `crew/guards/pii.py`를 고칩니다. 가린 자리마다 번호를 붙이고 짝을 남깁니다. 이메일 패턴도 더합니다.
   ```python
   PATTERNS = [
       ...,
       ("이메일", re.compile(r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+")),
   ]
   RESTORE = {"전화", "이메일"}  # 고객 본인에게 되돌려 보여도 되는 것. 카드·주민번호는 되돌리지 않는다


   def mask(text: str) -> tuple[str, dict[str, str]]:
       mapping: dict[str, str] = {}

       def keep(label: str, value: str) -> str:
           key = f"[MASKED:{label}#{len(mapping) + 1}]"
           mapping[key] = value
           return key

       for label, pattern in PATTERNS:
           text = pattern.sub(lambda m, label=label: keep(label, m.group(0)), text)
       for name in _presidio(text):
           text = text.replace(name, keep("이름", name))
       return text, mapping


   def unmask(text: str, mapping: dict[str, str]) -> str:
       for key, value in mapping.items():
           label = key[len("[MASKED:"):].split("#")[0]
           text = text.replace(key, value if label in RESTORE else f"[MASKED:{label}]")
       return text
   ```
3. Presidio는 선택입니다. `_presidio()`는 설치돼 있으면 사람 이름을 더 찾고, 없으면 빈 목록을 돌려줍니다(정답 파일 참고).
4. 게이트웨이가 답이 나온 뒤 `unmask()`를 부릅니다. 짝은 요청 하나 동안만 메모리에 있고, 어디에도 저장하지 않습니다.
5. 확인합니다.
   ```bash
   make check L=4-4
   ```
